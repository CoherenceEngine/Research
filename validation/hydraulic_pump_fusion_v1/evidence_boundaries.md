# Evidence boundaries and IP controls

**Evidence status: RETROSPECTIVE / INTERNAL EXECUTION / EXTERNAL VALIDATION PENDING.**

The new public hydraulic summary supports a limited statement: on one UCI hydraulic test rig, EWMA combined with a diagnostic signal from The Coherence Engine™ showed greater **pump-leak condition discrimination** than EWMA alone (AUROC 0.757 versus 0.640). The block-aware analysis followed earlier inspection of the same held-out results.

The retrospective alarm comparison at a strict pump-leak-negative calibration budget detected 16/45 positive blocks versus 8/45 for EWMA. Both had zero observed alerts on 43 pump-leak-negative evaluation blocks. This does not prove zero false alarms or independent superiority. The combined detector still missed 29/45 positive blocks.

**Negative result:** Three-regime normalization lowered fusion AUROC to approximately 0.620 versus 0.757 for the global adapter.
